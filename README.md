# ⛏️ mc-files

MC 风格文件分享网盘：**访客只读可下载，管理员解锁后上传 / 删除**。

## 文件
| 文件 | 作用 |
|---|---|
| `index.html` | 站点结构 + GitHub API 核心逻辑 |
| `beautify.js` | **独立 UI 层**（未内嵌）：PBKDF2 管理员鉴权（首次自设密码 / 管理态改密）、访客只读、拖拽上传、>100MB 分卷、多选下载、右下角 Toast |
| `.meta.json` | 分类 / 简介 / 分卷标记，UTF-8 |
| `README.md` | 本文件 |

## 部署
```bash
git add -A && git commit -m "站点整合版" && git push
# Settings → Pages → main / root → Save
```
访问：`https://chachacha1437god.github.io/mc-files/`

## 使用
- **访客**：列表、直链 / 镜像、多选下载；看不到上传区与删除按钮。
- **解锁管理员**：右下角「🔒 管理员」→ 首次自己设密码（≥6 位，哈希只存本机）→ 上传区与删除按钮滑出。
- **改密码**：管理员面板填「当前 + 新密码」→ 改完自动退出，下次用新密码进。错 3 次锁 30 秒。
- **>100MB**：勾「🧩 分卷上传」，自动切 90MB/卷，列表归成一条「分卷」标；下载时自动把全部卷一并拉下。

> Token 只存浏览器本地，只勾 `repo` 权限，用完可 revoke。此锁为浏览器端门面锁，非服务器鉴权。
